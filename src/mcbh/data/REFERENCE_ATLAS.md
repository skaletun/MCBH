# MCBH reference atlas

For the **illustrated Minecraft screenshot studies** and source credits see [VISUAL_ATLAS](https://github.com/skaletun/MCBH/blob/main/docs/VISUAL_ATLAS.md).

Always study a real finished-building image, a photo from the construction stage, a block palette, the roof profile, facade depth, interior plan and ground contact. Apply the techniques to original coordinate-based geometry. Check version and texture pack; an unusual block may be mod-only. RCON does not deliver screenshots.
